# Omarchy configuration

This directory preserves the active user-owned Omarchy configuration from:

- `~/.config/hypr` in `hypr/`
- `~/.config/waybar` in `waybar/`

The snapshots include every active regular configuration file and exclude timestamped backup files. They are reference copies and are not installed or symlinked automatically.

After reinstalling or updating Omarchy, compare these files with the newly installed `~/.config` files before restoring them. Never copy them into Omarchy's managed `~/.local/share/omarchy` directory.
